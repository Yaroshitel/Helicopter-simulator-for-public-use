# Helicopter Flying Simulator — desktop edition (Windows, macOS & Linux)

A native desktop version of the simulator: its own game and its own app. It does **not** run in a browser and does not
use any web engine (no Chrome, no Edge/WebView2, no Safari/WebKit, no Electron). It is built with the
[Godot Engine](https://godotengine.org) (MIT licence) and renders directly through the graphics card
(Vulkan / Direct3D 12 on Windows, Metal on macOS, with an OpenGL fallback for older machines).

Typical memory use is a few hundred MB, much less than the browser version needs.

## Download & run

Download the app once from the **[latest release](https://github.com/Yaroshitel/Helicopter-simulator-for-public-use/releases/latest)**:

| Platform | File | How to start |
|---|---|---|
| Windows 10/11 (64-bit) | `HelicopterSim-Windows.zip` | Unzip, double-click `HelicopterSim.exe` |
| macOS 11+ (Apple Silicon and Intel, universal) | `HelicopterSim-macOS.zip` | Unzip, drag `Helicopter Flying Simulator.app` to Applications, then open it (see below) |
| Linux (x86-64) | `HelicopterSim-Linux.zip` | Unzip, run `./HelicopterSim.x86_64` |

No installation and no browser are needed, and the game runs without an internet connection.

### Updates

You only download the zip once. When the game starts it checks for a newer build. If there is one, it asks
**Update / Not now**. The update downloads in a few seconds and the game starts on the new version.

- Updates come in two parts: the **mechanics** (`game.pck`: flight model, cockpits, UI, sound, a few hundred KB)
  and the **world** (`world.pck`: terrain and the valley builder, about 2.5 MB). The world is only downloaded when
  it actually changed.
- Downloads are checked against SHA-256 checksums before they are used. A failed or damaged download changes
  nothing, and you can keep playing the version you have.
- Offline, the game simply starts the newest version already on your computer.
- If a downloaded build ever fails to start twice in a row, the game falls back to the version that came in the zip.
- Updated files are kept in Godot's user-data folder (`%APPDATA%\Godot\app_userdata\Helicopter Flying Simulator\update`
  on Windows, `~/Library/Application Support/Godot/app_userdata/Helicopter Flying Simulator/update` on macOS,
  `~/.local/share/godot/app_userdata/Helicopter Flying Simulator/update` on Linux). Delete that folder to go back to
  the version from the zip.
- A new full download is only needed if the game engine itself is upgraded. The game tells you when that happens.

**First start on Windows:** the app is not code-signed (signing needs a paid certificate), so SmartScreen may say
"Windows protected your PC". Click **More info → Run anyway**.

**First start on macOS:** the app is ad-hoc signed but not notarised by Apple (notarisation needs a paid Apple Developer
account), so Gatekeeper blocks the first launch. Either right-click the app → **Open** → **Open**, or go to
**System Settings → Privacy & Security** and click **Open Anyway**. If macOS says the app "is damaged", run once in Terminal:

```bash
xattr -dr com.apple.quarantine "/Applications/Helicopter Flying Simulator.app"
```

## What is in it

Everything from the web version, ported to native code:

- Robinson R44 and Mil Mi-8MTV with the same flight model (rotor RPM, governors, ground effect, translational lift,
  torque, vortex ring state, turbine lag, autorotation, dynamic inflow, optional SAS)
- Heavy, deliberate handling: small stick movements do little and the last part of the travel gives the real
  authority; a held stick settles at a held attitude; the airframe's inertia makes rates build and stop gradually.
  The tail rotor's sideways push is cancelled by the rotor rigging, and only changes in torque (a quick collective
  pull) swing the nose. Keyboard pedals spring back to centre, which holds the heading.
- Full cold-start and shutdown lessons that tick off automatically and highlight the next control
- Clickable cockpits: every switch, lever and gauge explains itself (hover, or hold **Alt** and aim)
- Live instrument panels, pilot's manual (**M**) with a live guide to every round instrument
- The river-valley world: airfield, lake, river, town, ferro-alloy plant with smoking chimneys, railway, bridge, traffic,
  forests, vineyards, hilltop church, high-voltage line
- Day/night cycle with sun, moon, stars, night lighting
- Detailed graphics, all generated by the program:
  - Ground drawn by one terrain shader: meadows with several scales of variation, fields with furrows and hedges,
    forest floor, gravel river banks, rock on steep slopes, snow on the tops, smooth per-pixel lighting. Apron, pad,
    runway, roads and rails are drawn so they can never flicker or blend into the ground or into each other.
  - 3D grass around you that sways in the wind and is pressed flat and fanned out by the rotor downwash
  - Leafy broad-leaved trees and branchy spruces that move in the wind, with smooth distance fading
  - Sky with a moving, sunlit cumulus layer (warm at sunrise and sunset), twilight glow, stars at night
  - Clear water: you see the gravel bed in the shallows, deep teal further out, ripples, sky reflections, foam at the bank
  - Concrete slabs with joints, cracks and patches, a taxiway with painted lead-in lines, tiled roofs with chimneys,
    shiny windows, proper car shapes, lit windows at night
  - R44: painted livery with cheat-line and rivet rows, landing lights, door handles and hinges, antennas, louvres;
    leather seats with harnesses, carpet, wrinkle-finish panel with glare shield and compass, circuit breakers,
    rubber grips, gauges with bezels and glass
  - Mi-8: riveted skin with soot and weathering, sliding door with rails, entry step, tank straps, antennas;
    leather seats with armour plates, turquoise consoles with switch banks, the cockpit fans, standby compass,
    gauges with glass
- Procedural engine, turbine, rotor and tail-rotor sound
- Graphics quality setting (Low / Medium / High) on the start screen and in the side panel. High adds 3D grass
  further out, ambient occlusion, bounced light, screen-space reflections and sharper, softer shadows.

## Controls

| Input | Action |
|---|---|
| Mouse | Cyclic (roll / pitch) — click the view to capture the mouse |
| W / S | Collective up / down |
| A / D | Yaw pedals left / right (spring back to centre on release) |
| T / G | Throttle (R44) / correction grip (Mi-8) |
| Hold Alt | Free look — aim the dot at a switch and click (right-click = back) |
| V / C | 1st ⇄ 3rd person / cycle cameras |
| M | Pilot's manual |
| Space / X | Centre cyclic / pedals |
| N | Advance the time of day by one hour |
| P / Backspace | Pause / reset |
| F11 | Full screen |
| Esc | Release the mouse |

Without capturing the mouse you can also point at switches and click them directly, and drag with the right mouse button to look around. Gamepads are supported.

## Building from source

The Godot project is in [`native/`](native/). You need Godot 4.4.1 and its export templates.

```bash
cd native
./build.sh 0
```

`build.sh [build-number] [notes]` exports the three apps and the two update packs and writes `manifest.json`, all
into `build/release/`. Exports work from Windows, macOS or Linux.

**Releases are automatic.** Every push to `main` that touches `native/` runs
[`.github/workflows/release.yml`](.github/workflows/release.yml). It runs the flight-model tests, builds
everything and publishes a GitHub Release named `Build <n>`. Installed games pick that release up on their next
start. The world id is a hash of the world's own files (`baked/*.bin`, `scripts/world_builder.gd`,
`shaders/world/*.gdshader`), so players only download the world when one of those changed.
The terrain is pre-baked into `native/baked/`. If you change the valley layout in `scripts/util.gd`, re-bake it with
`godot --headless -s tools/bake_terrain.gd`.
