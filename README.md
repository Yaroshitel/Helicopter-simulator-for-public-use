# R44 Trainer

A browser-based Robinson R44 helicopter training simulator built with three.js.

**▶ Play:** https://yaroshitel.github.io/r44-trainer/

- Start the helicopter from cold, switch by switch: battery, fuel, mixture, magnetos, starter, clutch, governor
- Hover over (or aim at, with Alt) any switch or gauge to learn what it does
- Built-in pilot's manual (press **M**) with engine pictures, diagrams and a guide to reading every round instrument
- HD procedural textures and normal maps (rivets, panel seams, concrete joints, asphalt, brushed metal)
- Flight model with rotor RPM, ground effect, translational lift, torque, vortex ring state and autorotation
- Procedural engine, rotor and tail-rotor sound

## Controls

| Input | Action |
|---|---|
| Mouse | Cyclic (roll / pitch) |
| W / S | Collective up / down |
| A / D | Yaw pedals left / right |
| T / G | Throttle open / close |
| Hold Alt | Free look — aim the dot at a switch and click (right-click = back) |
| V / C | 1st ⇄ 3rd person / cycle cameras |
| M | Pilot's manual |
| Space / X | Centre cyclic / pedals |
| Esc | Release the mouse |

Runs in Chrome or Edge on a desktop. Needs an internet connection to load three.js from a CDN.

*For learning and entertainment only — not an approved training device and not a substitute for the R44 Pilot's Operating Handbook.*
